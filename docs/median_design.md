# Защита вычисления медианы

Медиана вычисляется на отсортированной **копии**, чтобы исходный массив
не изменялся. Для чётного количества элементов среднее двух центральных
значений считается после приведения каждого операнда к `double`, что
предотвращает целочисленное переполнение на `INT_MIN` и `INT_MAX`.

Отдельный регрессионный тест `test_median_extra` покрывает граничные значения,
повторяющиеся элементы и неизменность массива.
